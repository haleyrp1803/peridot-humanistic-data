# Tabler Icons — MIT license and Peridot provenance

Selected Timeline category symbols are sourced from **Tabler Icons v3.50.0**
(https://github.com/tabler/tabler-icons), created by Paweł Kuna and contributors.
The Peridot symbol library uses 100 individually curated icon names through the
`@tabler/icons-react@3.50.0` package. Only the named icons are imported into
Peridot's Timeline category rendering code. This library is not fetched from an
external server at runtime. The existing Peridot-drawn legacy symbols are
retained for compatibility with previous session selections.
